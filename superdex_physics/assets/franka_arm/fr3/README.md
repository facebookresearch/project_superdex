# Franka FR3 Arm

This directory contains a simplified robot description of the [Franka Research 3 (FR3)](https://franka.de/products) derived from the corresponding model in [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie/tree/main/franka_fr3).

The assets were converted to the SuperDex Physics format and adapted with simulation-ready collision geometry, dynamics parameters, and rendering meshes.
