# Duck Description

## Overview

This package contains a Meta-authored rubber-duck asset modeled by hand. No third-party digital model or geometry was used.

## Derivations

The following work was done to produce the simulation-ready asset:

- Hand-modeled the geometry.
- Generated collision geometry and simulation-ready rigid, deformable, and reduced-order variants.
- Retuned dynamic parameters for simulated behavior.
- Adjusted visual appearance for rendering.
