# SuperDex Physics Editor Icons

## Overview

This directory contains the Unreal Editor asset icons for the SuperDexPhysics plugin. Each asset type has a 16x16 class icon (`<ClassName>_16.svg`) and a 64x64 thumbnail (`<ClassName>_64.svg`), registered as `ClassIcon.<ClassName>` and `ClassThumbnail.<ClassName>` by the plugin's editor module.

| Icon | Asset type |
| --- | --- |
| `MochiModel` | Mochi Model |
| `MochiMaterialParams` | Mochi Material Params |
| `MochiShellMaterialParams` | Mochi Shell Material Params |
| `MochiRodMaterialParams` | Mochi Rod Material Params |
| `MochiContactParams` | Mochi Contact Params |
| `MochiContactMatrix` | Mochi Contact Matrix |
| `MochiSolverParams` | Mochi Solver Params |
| `MochiModelMaterialModifiers` | Mochi Model Material Modifier |
| `MochiArticulation` | Mochi Articulation |
| `SuperDexPrefab` | SuperDex Prefab |

`Icon128.png` is the plugin icon shown in the Unreal Editor's Plugins browser. It is the SuperDex Physics icon from the SuperDex website, drawn in white on the black rounded square of the SuperDex logo.
