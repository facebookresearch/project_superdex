# SuperDex Examples for Unreal

## Overview

This content-only plugin holds example levels for the SuperDexPhysics and SuperDexRobotics
plugins. It needs those plugins and SuperDexAssets.

| Level | Contents |
| --- | --- |
| `Content/Sampler/L_Sampler` | A table on which `BP_Sampler_PrefabSpawner` spawns the SuperDexAssets task prefabs one at a time, for trying them in SuperDex Physics |
