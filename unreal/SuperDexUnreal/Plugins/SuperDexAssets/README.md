# SuperDex Assets for Unreal

## Overview

This content-only plugin holds Unreal Engine versions of SuperDex task prefabs for the
SuperDexPhysics and SuperDexRobotics plugins. Each prefab was imported from the SuperDex prefab of
the same name in the repository's
[`assets/prefabs`](https://github.com/facebookresearch/project_superdex/tree/main/assets/prefabs),
whose README records how the asset was made. The digital assets are the original work of Meta
Platforms, Inc. and affiliates. They were modeled in-house; no third-party digital source files
were used.

| Folder | Prefab | Modeled after |
| --- | --- | --- |
| `Content/prefabs/brick_toys` | A 2x2 large interlocking brick toy | No particular product |
| `Content/prefabs/functional_dexterity_test` | A Functional Dexterity Test pegboard and peg | North Coast Functional Dexterity Test, model NC32152 (North Coast Medical) |
| `Content/prefabs/nine_hole_peg_test` | A nine-hole peg test board and peg | Baseline 453602 9-Hole Wooden Pegboard (Fabrication Enterprises, Inc.) |
| `Content/prefabs/paper_cups` | A paper cup and a ten-cup pyramid | 8 oz ecotainer Hot Cup, Carte Blanc, SKU SMRE8-CB (Graphic Packaging International) |
| `Content/prefabs/puzzle_cube` | A 2x2 puzzle cube articulation | No particular product |
| `Content/prefabs/shape_box` | A shape sorting box with 12 shapes | Melissa & Doug Shape Sorting Cube (Melissa & Doug) |
