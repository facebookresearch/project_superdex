# SuperDex Robotics Editor Icons

## Overview

This directory contains the Unreal Editor asset icons for the SuperDexRobotics plugin. Each asset type has a 16x16 class icon (`<ClassName>_16.svg`) and a 64x64 thumbnail (`<ClassName>_64.svg`), registered as `ClassIcon.<ClassName>` and `ClassThumbnail.<ClassName>` by the plugin's editor module.

| Icon | Asset type |
| --- | --- |
| `SuperDexBot` | SuperDex Bot |
| `SuperDexScene` | SuperDex Scene |
| `SuperDexBotIKConfig` | SuperDex Bot IK Config |
| `SuperDexPoseAsset` | SuperDex Pose Asset |
| `SuperDexStudyQuestionData` | SuperDex Study Question Data |

`Icon128.png` is the plugin icon shown in the Unreal Editor's Plugins browser. It is the SuperDex Robotics icon from the SuperDex website, drawn in white on the black rounded square of the SuperDex logo.

The icons are the original work of Meta Platforms, Inc. and affiliates. They were designed in-house for SuperDex; no third-party icons or digital source files were used.
