SuperDex Physics can be installed as part of Project SuperDex. Follow the
[Project SuperDex build instructions](https://github.com/facebookresearch/project_superdex#building-from-source)
to install it and its dependencies.

To test your installation, explore the documented [Examples](./examples/0_getting_started.md).
