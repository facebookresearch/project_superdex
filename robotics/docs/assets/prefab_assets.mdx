# Prefab Assets

SuperDex ships a library of physics prefabs under `assets/prefabs/`. A prefab is
a JSON file (`.superdex_prefab`, or `.mochi_prefab` for older assets) that
declares rigid, soft, articulated, and rod actors with their materials,
collision models, and render models. Add one to a SuperDex Physics scene, open
it in the <ProjectSuperdexLink site="studio" path="docs/prefab_editor/">Studio
Prefab Editor</ProjectSuperdexLink>, import it into SuperDex Unreal, or list it
as a spawnable prefab in a [SuperDex scene](../superdex_scenes.mdx). For the
format, see
<ProjectSuperdexLink site="physics" path="docs/authoring_scenes/authoring_prefabs/">Authoring
Prefabs</ProjectSuperdexLink>.

Each folder holds a main prefab and, where useful, variants of it, such as a
task's starting arrangement. Many folders also have a `tuning/` subfolder of
<ProjectSuperdexLink site="studio" path="docs/asset_tuner/">Asset Tuner</ProjectSuperdexLink>
experiments that check the prefab's behavior,
for example how hard a key must be pressed or how firmly a plug seats. The
**Bodies** column lists the actor types the main prefab uses.
