# FR3 V2.1 URDF Test Asset

This directory contains a generated Franka FR3 V2.1 with Franka Hand URDF and its visual and collision meshes from the [Franka Robotics `franka_description` package](https://github.com/frankarobotics/franka_description), version 2.8.1.

The assets are provided under Apache-2.0; see [`LICENSE`](LICENSE) and the notices embedded in the COLLADA files.
