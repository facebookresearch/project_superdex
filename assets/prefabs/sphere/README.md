# Sphere Prefab

## Overview

This package contains a Meta-owned sphere prefab for use in SuperDex simulations. The digital geometry is the original work of Meta Platforms, Inc. and affiliates. It was modeled in-house; no third-party digital source files were used.

## Modifications and Processing

- Manually authored the sphere geometry in SolidWorks and exported a STEP interchange model.
- Generated GLB and OBJ render geometry from the source CAD, including the chrome material variant in `sphere_chrome.glb`.
- Generated collision geometry for SuperDex Physics.
- Assembled the asset as `sphere.mochi_prefab`.
