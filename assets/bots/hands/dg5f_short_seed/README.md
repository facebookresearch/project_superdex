# DG-5F-M Short-Wrist Hand with Seed Sensors

This directory contains a SuperDex assembly that references:

- Tesollo DG-5F-M short-wrist hand: [`../dg5f_short`](../dg5f_short) — see its README, LICENSE, and NOTICE.
- Seed Robotics SINGLEX-3 sensor package: [`../../sensors/dg5f_seed`](../../sensors/dg5f_seed) — see its README, LICENSE, and NOTICE.

The assembly also contains Meta-authored fingertip-mount geometry. Each of the following files is present under both `left/` and `right/`:

- `render/dg5f_link_1_4_mount_render.glb`
- `render/dg5f_link_234_4_mount_render.glb`
- `render/dg5f_link_5_4_mount_render.glb`
- `collision/dg5f_link_1_4_mount_collision.mochi.h5`
- `collision/dg5f_link_234_4_mount_collision.mochi.h5`
- `collision/dg5f_link_5_4_mount_collision.mochi.h5`
