# Meta XR Hand Description

## Overview

This package contains Meta-owned hand models (high- and low-poly variants) based on Meta's XR hand rig, adapted for use as robot descriptions in SuperDex Robotics. The geometry is the original work of Meta.

The public asset name is **Meta XR Hand**. Legacy `oculus_xr` directory and filename identifiers are retained for source compatibility only.
