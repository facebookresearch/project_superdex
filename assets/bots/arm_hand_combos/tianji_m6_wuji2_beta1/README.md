# Tianji Marvin M6 with Wuji Hand 2 (Beta 1)

This directory contains SuperDex assemblies for both arms:

- Left: [`left/tianji_m6_wuji2_beta1_left.superdex_bot`](left/tianji_m6_wuji2_beta1_left.superdex_bot)
- Right: [`right/tianji_m6_wuji2_beta1_right.superdex_bot`](right/tianji_m6_wuji2_beta1_right.superdex_bot)

Each attaches the skinned Wuji Hand 2 directly to the arm's tool flange (`TCP_Link_L` / `TCP_Link_R`), turned 90 deg about the flange axis. Each references:

- Tianji Marvin M6-S-CCS-696-V4.0 arm: [`../../arms/tianji_m6`](../../arms/tianji_m6) - see its README, LICENSE, and NOTICE.
- Wuji Hand 2 (Beta 1), skinned: [`../../hands/wuji_hand2_beta1`](../../hands/wuji_hand2_beta1) - see its README, LICENSE, and NOTICE.
