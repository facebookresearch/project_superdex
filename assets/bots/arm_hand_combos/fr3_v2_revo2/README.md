# FR3 V2 with BrainCo Revo2 Hand

This directory contains SuperDex assemblies of a Franka Research 3 arm carrying a BrainCo
Revo2 hand with fingertip tactile sensors:

- `fr3_v2_revo2_right.superdex_bot`, `fr3_v2_revo2_left.superdex_bot`

They reference:

- Franka FR3 V2 arm: [`../../arms/fr3_v2`](../../arms/fr3_v2) — see its README, LICENSE, and NOTICE.
- BrainCo Revo2 hand: [`../../hands/revo2`](../../hands/revo2) — see its README, LICENSE, and NOTICE.

The hand sits on a generic adapter (`fr3_revo2_mount`, 15 mm, 101 g aluminum) with the
same -45° flange yaw as the Franka Hand. BrainCo does not publish its adapter, so the
mount is a parametric part generated by
[`tools/build_revo2_assets.py`](../../../../tools/build_revo2_assets.py) and is provided
under the same terms as this repository's first-party assets.

## Coupled finger joints

`superdex-robotics` 1.0.0 does not carry an attached hand's `linearTransmissions` into
the combo, which leaves the Revo2's distal joints uncoupled. The engine fix is in
`superdex_robotics/src/utils/bot_utils.cpp`; with the 1.0.0 wheels, load the combo
through `superdex.lab.gym.utils.bot_loading.load_bot_prefab`, which restores them.

## Simulation environment

`superdex_gym/Fr3Revo2-v0` (`superdex_lab/superdex/lab/gym/envs/robots/fr3_revo2_env.py`)
wraps this robot in a grasp-and-lift task with the five tactile pads in the observation.
